# 06: Rules and design

## Visual
- Colours: **burgundy, gold, white only** (`src/theme.ts`).
- **Gold only on the plant/lotus** (plus the existing Verified badge and plant badge in the base, so check those with the user).
- Each screen gets **a badge or one main button**, never several competing ones.
- Muted white text at **≥ 64% opacity** (`C.w64`). Nothing lower.
- Mobile only (iOS/Android). Web is only a test target.
- Don't redesign the existing screens.

## Copy
- English UI.
- **"Circle", never "group".**
- Chats have **"safety built in"**. Never say "monitored".
- Wellbeing is a layer, not the headline. Don't call it social media.
- Hope Node: concept/next step only, Faculty of Engineering for examples, **never "Rohban Hall"**.
- Nicknames are never real names. The care level is never a number.

## Privacy
- Survey: only "28-student survey" (aggregate). No contacts, no individual answers.
- No real student data in the repo or seeds.
